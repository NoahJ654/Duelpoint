# DuelPoint

A Yu-Gi-Oh! tournament manager.

## Features

- Swiss tournament format
- Supports up to 16 players
- 3 points per win, 0 points per loss
- Automatic standings and rankings
- 50-minute match timer
- 5-minute result-entry period
- Tournament results and player records

## Technology

- HTML
- CSS
- JavaScript
- Supabase for shared tournament data
- GitHub Pages for hosting
